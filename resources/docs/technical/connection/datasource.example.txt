DATA CONNECTION TEMPLATE
Data Source Documentation Framework

PURPOSE
This template documents the information required to reconstruct
access to a dashboard's data source(s). It does not contain
credentials or usernames - those are handled individually with the
data/system owner. Do not commit to Git or public repositories.

USAGE
Duplicate this file per dashboard/report. Fill in only the section(s)
matching the source type(s) in use. Refer to the GLOSSARY section at
the end for guidance on any field.

========================================================
GLOSSARY / QUICK REFERENCE
========================================================

IMPORT
Brings the data into Power BI and stores it in the file. Refreshes
according to the scheduled cadence. The most common mode: better
report performance, but data is not "live" until the next refresh.

DIRECTQUERY
Queries the database in real time every time someone opens or
interacts with the report. Used when data changes very frequently or
volume is too large to import in full. Can be slower and depends on
the database being available at all times.

DUAL
A mixed mode configured after connecting (not at connection time),
table by table, within Power BI Desktop. Used when a single model
combines Import and DirectQuery tables. Does not apply unless the
dashboard is a composite model.

ORGANIZATIONAL ACCOUNT
Authentication using the organization's Microsoft 365 / Entra ID
account. The most common choice for SharePoint Online.

MICROSOFT ACCOUNT
Authentication using a personal (non-organizational) Microsoft account.

WINDOWS
Authentication typically used when SharePoint or the server is
on-premises (not cloud-hosted).

ANONYMOUS
Used when the site or folder allows public access without sign-in.

PRIVACY LEVEL (None / Public / Organizational / Private)
Not an authentication method - a separate setting that tells Power BI
how freely this source's data can be combined with other sources
during processing.

MYSQL - NATIVE METHOD ("MySQL database")
Power BI's built-in MySQL connector. Requires installing the MySQL
Connector/NET driver separately (only 8.0.x versions are compatible;
9.x versions do not work with this connector).

MYSQL - ODBC
Generic connection through a DSN (Data Source Name) configured with a
MySQL ODBC driver. The most frequently used method. The DSN must exist
identically configured on both the publishing/refresh machine and the
gateway machine, if applicable.
